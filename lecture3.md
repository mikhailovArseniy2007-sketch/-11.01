# Векторы и строки

Базовые контейнеры стандартной библиотеки

### Контейнер `std::vector`

Вектор `std::vector` - динамический массив, обеспечивающий быстрое добавление новых элементов в конец массива и при необходимости меняющий свой размер.

Вектор гарантирует отсутствие утечек памяти.

Пример:

```
void task1()
{
  std::vector<int> data = {1, 2, 3, 4, 5 };
  for (int elem : data)
  {
    cout << elem;
  }
  cout << "\n";
}
```

### Инициализация списка

```
#include <string>
#include <vector>

int main() {
  std::vector<std::string> v1; // Пустой вектор
  std::vector<std::string> v2(5); // Вектор из пяти пустых строк
  std::vector<std::string> v3(5, "helloy"); // Вектор из пяти строк "helloy"
}
```

### Обращение к элементами

```
int a = data[0]; // получили первый элемент вектора
int b = data[4]; // получили пятый элемент вектора
data[2] = -3; // меняем третий элемент на -3
```

### Размер списка

`std::cout << data.size() << "\n";`

Отрицательные индексы, как в некоторых других языках программирования, не допускаются.

### Итерация по индексам

В стандартной библиотеке индексы и размеры контейнеров имеют беззнаковый тип.

Вместо `usingned int` для него используется традиционный псевдоним `size_t`.

Его использование в программе дополнительно подчёркивает, что мы имеем дело с индексами или с размером.

```
void example()
{
  std::vector<int> data(5);
  cout << "Enter numbers:";

  // Заполнение вектора
  for (size_t i = 0; i != data.size();i++)
  {
    cout << data[i];
    cout << ' ';
  }
}
```
