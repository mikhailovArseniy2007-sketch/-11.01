# Векторы и строки

Базовые контейнеры стандартной библиотеки

### Контейнер `std::vector`

Вектор `std::vector` - динамический массив, обеспечивающий быстрое добавление новых элементов в конец массива и при необходимости меняющий свой размер.

Вектор гарантирует отсутствие утечек памяти.

Пример:

```
void task1()
{
  std::vector<int> data = {1, 2, 3, 4, 5 };
  for (int elem : data)
  {
    cout << elem;
  }
  cout << "\n";
}
```

### Инициализация списка

```
#include <string>
#include <vector>

int main() {
  std::vector<std::string> v1; // Пустой вектор
  std::vector<std::string> v2(5); // Вектор из пяти пустых строк
  std::vector<std::string> v3(5, "helloy"); // Вектор из пяти строк "helloy"
}
```
